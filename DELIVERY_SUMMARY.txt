SUPPORT
===============================================================================

IF STYLES NOT APPLYING:
  1. Verify CSS is at END of <style> tag (higher specificity)
  2. Hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
  3. Check browser console for errors

IF HORIZONTAL SCROLLING:
  1. Verify width: 90vw (not 100vw)
  2. Check max-width: 90vw is set
  3. Confirm overflow-x: hidden on cart drawer

IF BUTTONS STILL LOOK SMALL:
  1. Test on real device (not just DevTools)
  2. Verify min-height: 44px applied
  3. Check padding doesn't interfere

IF DESKTOP CHANGED:
  1. Verify media queries use max-width: 1024px or lower
  2. Check desktop rules use min-width: 1025px
  3. Look for accidentally modified global rules

IF HAMBURGER MENU DOESN'T WORK:
  1. Verify HTML IDs match JavaScript selectors
  2. Add the JavaScript code from IMPLEMENTATION_GUIDE.md
  3. Check browser console for errors
