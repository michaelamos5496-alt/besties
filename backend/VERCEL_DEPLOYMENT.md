# Vercel Deployment Guide

Deploy your Besties payment backend to Vercel in 5 minutes.

---

## 📋 Files to Upload to GitHub

### ✅ Upload These Files:
```
backend/
├── server.js          ✅
├── package.json       ✅
├── vercel.json        ✅
├── .gitignore         ✅
├── README.md          ✅
└── FRONTEND_INTEGRATION.md ✅
```

### ❌ Do NOT Upload:
```
.env                   ❌ (contains secrets)
node_modules/          ❌ (regenerated by npm)
.DS_Store              ❌ (system file)
```

## 🚀 Step-by-Step Deployment

### Step 1: Push to GitHub

```bash
cd backend

# Initialize git (if not already done)
git init

# Add files
git add server.js package.json vercel.json .gitignore README.md FRONTEND_INTEGRATION.md

# Commit
git commit -m "Initial commit: Besties MTN payment backend"

# Push to GitHub
git push -u origin main
```

### Step 2: Connect to Vercel

1. Go to https://vercel.com
2. Sign in or create account
3. Click **"New Project"**
4. Select your GitHub repo
5. Click **"Import"**

### Step 3: Add Environment Variables

In Vercel dashboard:

1. Click **"Settings"** → **"Environment Variables"**
2. Add these variables:

```
MTN_CONSUMER_KEY = 74DFhEq4CAw0Ah3yzj0cRESv6R0ZdaO1
MTN_CONSUMER_SECRET = zS0eD3zxz6CUGpXO
MTN_MERCHANT_ID = BESTIES_GH_001
MTN_MERCHANT_PHONE = +233541479680
MTN_API_URL = https://api.mtn.com/mtn_payment_sandbox
CALLBACK_URL = https://your-deployment.vercel.app/api/mtn-callback
NODE_ENV = production
```

### Step 4: Deploy

1. Click **"Deploy"**
2. Wait 2-3 minutes
3. You'll get a URL like: `https://your-app.vercel.app`

### Test Your API:

```bash
curl https://your-deployment.vercel.app/api/health
```

```json
{
```

```javascript

```

## 🔐 Important Security Notes

1. **Never commit `.env`** - Use Vercel's environment variables instead
2. **Use `.gitignore`** - Already created for you
3. **Keep secrets safe** - Don't share your API keys
4. **Update callback URL** - Point to your Vercel deployment

## 🆘 Troubleshooting

**Issue**: Deployment fails
- Check `.gitignore` - make sure `.env` is NOT committed
- Check `vercel.json` syntax
- View Vercel logs for errors

**Issue**: Payment not working
- Verify environment variables in Vercel
- Check callback URL is correct
- Review server logs in Vercel dashboard

**Issue**: 502 Bad Gateway
- Check `server.js` for errors
- Verify all dependencies in `package.json`
- Check Node.js version compatibility
